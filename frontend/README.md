# 🛒 Full Stack E-Commerce App (MERN)

A production-quality MERN stack e-commerce application built module by module.

## Tech Stack

| Layer | Technology |
|-------|-----------|
| Frontend | React (Vite), Redux Toolkit, Tailwind CSS, Axios |
| Backend | Node.js, Express.js |
| Database | MongoDB Atlas |
| Auth | JWT + bcrypt |
| Image Upload | Cloudinary + Multer |

## Quick Start

### Backend
```bash
cd backend
cp .env.example .env
# Add your MongoDB Atlas URI to .env
npm install
npm run dev
```

### Frontend
```bash
cd frontend
npm install
npm run dev
```
